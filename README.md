# Mon premier projet

Ce depot sert a m'entrainer a faire ma premiere Pull Request sur GitHub.

## A propos

Cree pour apprendre le workflow Git/GitHub : creer une branche, faire un commit, et ouvrir une pull request.

## Etapes du workflow Git/GitHub

1. Creer une branche pour son changement
2. Faire des modifications et les committer
3. Pousser la branche sur GitHub
4. Ouvrir une Pull Request pour proposer le changement
